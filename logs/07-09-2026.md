### 2. NCI Accumulator Integration
**Implemented 20ms Non-Coherent Integration**
- Created `nci_accumulator.v` module with:
  - 4096 × 32-bit BRAM accumulators
  - Sequential clearing mechanism (4096 cycles = 20.48 µs)
  - `clear` input triggered by `acq_start` for each Doppler bin
  - `clear_done` output for handshake synchronization
  - Magnitude computation: `(I² + Q²) >>> 8` (shift to prevent overflow)

**State Machine Updates:**
- Added `ST_NCI_SCAN` state (4'd7) for peak detection
- Added `nci_count` register (5-bit, 0 to NCI_FRAMES-1)
- NCI loop in `ST_WAIT_INV`: loops back to `ST_WAIT_FIFO` until `nci_count == NCI_FRAMES - 1`
- `ST_NCI_SCAN`: sequentially reads all 4096 bins from NCI memory, finds peak

### 3. Parabolic Interpolation Implementation
**Added Sub-Chip Code Phase Resolution**

**Mathematical Foundation:**
- Formula: `Δx = (y_{-1} - y_{+1}) / (2(y_{-1} - 2y_0 + y_{+1}))`
- Where y_{-1}, y_0, y_{+1} are magnitudes at bins k-1, k, k+1
- Result: fractional offset between -0.5 and +0.5 chips

**Hardware Implementation:**
- **Approach:** Reciprocal LUT + DSP Multiplier (3-cycle pipeline)
- **Cycle 1:** Priority encoder normalizes denominator to 8-bit value (128-255)
- **Cycle 2:** Synchronous Block RAM read from reciprocal LUT
- **Cycle 3:** DSP48 multiplication and extraction

**Files Created:**
- `parabolic_interpolator.v` - Main interpolation module
- `generate_lut.py` - Python script to generate `reciprocal_lut.mem`
- `reciprocal_lut.mem` - 128-entry LUT file (indices 128-255)

**Integration:**
- Added `ST_INTERP` state (4'd9) to acquisition engine state machine
- Tracks `prev_peak_mag` during `ST_NCI_SCAN` to capture bin k-1 magnitude
- After scan, reads bin k+1 and triggers interpolator
- Added `best_code_phase_frac` output port (8-bit signed fractional offset)

## 📐 Technical Implementation Details

### NCI Accumulator Design
```verilog
module nci_accumulator #(
    parameter FFT_SIZE     = 4096,
    parameter DATA_WIDTH   = 18,
    parameter MAG_WIDTH    = 32
)(
    input  wire                    clk,
    input  wire                    rst_n,
    input  wire                    clear,          
    output wire                    clear_done,     // High when clearing complete
    input  wire                    fft_out_valid,
    input  wire signed [DATA_WIDTH-1:0] i_in,
    input  wire signed [DATA_WIDTH-1:0] q_in,
    output wire [MAG_WIDTH-1:0]    mag_out,
    input  wire [11:0]             read_addr
);
```

**Key Features:**
- Sequential clearing (4096 cycles) to avoid multi-driver conflicts
- Magnitude squared with `>>> 8` shift to prevent 32-bit overflow
- `clear_done` handshake ensures memory is ready before accumulation starts

### Parabolic Interpolator Design
```verilog
module parabolic_interpolator #(
    parameter MAG_WIDTH = 32,
    parameter FRAC_BITS = 8
)(
    input  wire clk,
    input  wire rst_n,
    input  wire start,
    input  wire [MAG_WIDTH-1:0] mag_minus_1,
    input  wire [MAG_WIDTH-1:0] mag_0,
    input  wire [MAG_WIDTH-1:0] mag_plus_1,
    output reg  signed [FRAC_BITS-1:0] frac_offset,
    output reg  done
);
```

**Implementation:**
- Priority encoder for denominator normalization
- 128-entry reciprocal LUT (Block RAM)
- DSP48 multiplier for fast division
- 3-cycle pipeline latency
- Output: 8-bit signed fractional offset (Q8 format)

### State Machine Flow
```
ST_IDLE → ST_WAIT_FIFO → ST_WIPEOFF → ST_LOAD_FWD → ST_STREAM_MULT
    ↓
ST_LOAD_INV → ST_WAIT_INV (loop NCI_FRAMES times)
    ↓
ST_NCI_SCAN (find peak, track prev_peak_mag)
    ↓
ST_INTERP (trigger parabolic interpolator)
    ↓
ST_DONE → ST_IDLE (pulse acq_done to controller)
```

## 🔬 Technical Notes

### NCI Scaling Explanation
**Why peak magnitude is ~10M instead of ~20M:**
- FFT internal scaling reduces output values
- NCI uses `>>> 8` shift to prevent overflow
- Math: I/Q ~2000 → squared ~4M → shifted /256 → ~15k per frame
- Accumulated 20 times: ~300k
- Actual peak: ~10M (includes FFT gain and correlation peak)

### Parabolic Interpolation Accuracy
- **Integer resolution:** 1 chip (FFT bin)
- **Fractional resolution:** 1/256 chip (~0.004 chips)
- **Total resolution:** ~0.004 chips = ~1.2 meters (theoretical)
- **Practical accuracy:** Limited by noise, multipath, and satellite geometry

## 💡 Key Learnings

1. **Self-contained IP design** makes modules reusable and testbenches simpler
2. **FFT output gating** is critical when sharing a single FFT IP between forward and inverse transforms
3. **BRAM clearing** must complete before new data arrives; use handshake signals (`clear_done`)
4. **Sequential scan** in NCI must compare before incrementing to avoid skipping index 0
5. **Reciprocal LUT + DSP** is the preferred method for division in FPGAs (fast, resource-efficient)
6. **Parabolic interpolation** provides significant accuracy improvement with minimal hardware cost
7. **XSim simulation time** scales linearly with total pipeline runs (11 bins × 20 frames = 220 runs)

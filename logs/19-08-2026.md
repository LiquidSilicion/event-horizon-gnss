## 1. Executive Summary
Today marked a major pivot and significant progress in the Event Horizon GNSS project. We formally transitioned away from the legacy Nakshatra/SDR porting approach and fully adopted the **"Architecting Centimeter-Accuracy"** framework. 

The primary focus was establishing a **deterministic, pipelined scalar tracking engine** in RTL, verifying its timing closure on the Zynq-7020, and developing the ARM-side C software for the loop filters. We successfully achieved simulation pass, synthesis timing closure, and stable software PLL convergence.

---

## 2. Key Architectural Decisions

| Decision | Rationale | Framework Principle |
| :--- | :--- | :--- |
| **Abandoned File-Based Testbenches** | Replaced fragile Python binary file I/O with a self-contained, cycle-accurate Verilog stimulus generator. | **Determinism**: Eliminates non-deterministic file I/O and endianness bugs. |
| **Bypassed AXI for Initial Synthesis** | Used a simple `tracking_top.v` wrapper with direct I/O ports instead of integrating the AXI4-Lite IP immediately. | **Modularity**: Isolates the core DSP datapath to verify pure timing closure before adding bus complexity. |
| **ILA via `(* mark_debug *)`** | Used Verilog attributes for debug probing instead of adding ILA IP in the Vivado Block Design. | **Simplicity**: Keeps the Block Design clean and avoids routing congestion during initial bring-up. |
| **Discrete-Time PLL Coefficients** | Replaced continuous-time loop filter math with discrete-time (Tustin/bilinear) coefficients to fix PLL divergence. | **Algorithmic Optimization**: Ensures the software loop filter is mathematically stable for 1ms discrete epochs. |
| **Finalized Bit-Widths (48/32/32/16)** | Locked in 48-bit Carrier NCO, 32-bit Code NCO, 32-bit Accumulators, and 16-bit Samples. | **Design Space Exploration (DSE)**: Proven to provide sub-nanometer resolution while minimizing DSP/BRAM usage. |

## 3. Phase 1: Scalar Hardware Baseline (RTL & Synthesis)

### 3.1 RTL Verification (Icarus Verilog)
*   **Action:** Rewrote `tb_tracking_channel.v` to generate an internal sinusoidal GPS L1CA stimulus (1250 Hz true Doppler, 1255 Hz local estimate).
*   **Result:** **PASS**. The correlator successfully locked, producing a stable `I_P` output of exactly **5,190,080** across 10 epochs.
*   **Significance:** Proves the 32-bit accumulators do not overflow and the 48-bit NCO maintains perfect phase alignment.

### 3.2 Vivado Synthesis & Timing Closure (Zynq-7020)
*   **Target Device:** xc7z020-clg484-1 (ZedBoard)
*   **Target Clock:** 100.000 MHz (10.000 ns period)
*   **Timing Results (from `report_timing_summary`):**
    *   **WNS (Setup):** **+1.823 ns** (MET)
    *   **WHS (Hold):** **+0.119 ns** (MET)
    *   **Critical Path:** DSP48E1 Mixer $\rightarrow$ CARRY4 $\rightarrow$ FDRE (8.177 ns delay).
*   **Resource Utilization:**
    *   **LUT:** 134 / 53,200 (0.25%)
    *   **FF:** 193 / 106,400 (0.18%)
    *   **BRAM:** 5 / 140 (3.57%) *(Sincos ROM + 3x C/A Code ROMs)*
    *   **DSP48:** 2 / 220 (0.91%) *(Carrier Mixer + MAC)*
*   **Significance:** The design is fully pipelined (II=1) with massive headroom. A single Zynq-7020 can theoretically support 28+ simultaneous channels.

## 4. Phase 2: Software Loop Filter & ARM Driver (C)

### 4.1 AXI4-Lite Driver Development
*   **Files Created:** `software/drivers/tracking_driver.h`, `tracking_driver.c`
*   **Implementation:** Memory-mapped I/O via `/dev/mem` to read/write the 6 correlator dumps (I_E, Q_E, I_P, Q_P, I_L, Q_L) and NCO control registers.
*   **Status:** Compiled successfully. Ready for hardware bring-up.

### 4.2 Loop Filter Implementation & Debugging
*   **Files Created:** `software/tracking/loop_filter.h`, `loop_filter.c`, `main_tracking.c`
*   **Initial Issue:** The PLL diverged wildly (frequency error grew to -67,000 Hz) because the initial coefficients were calculated for continuous time, not discrete 1ms epochs.
*   **The Fix:** Recalculated coefficients using the discrete-time natural frequency formula: $\omega_n = 2\pi B_n / (\zeta + 1/(4\zeta))$.
*   **Final Result:** **PASS**. 
    *   Initial Offset: 5.0 Hz
    *   Final Frequency Error: **0.000112 Hz**
    *   Convergence Time: ~300 ms
    *   Final State: $I_P \approx 5,000,000$, $Q_P \approx 0$ (Perfect carrier lock).

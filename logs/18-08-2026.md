## Phase 0: Golden Reference Establishment

### Synthetic Signal Generation
| Parameter | Value | Purpose |
|-----------|-------|---------|
| **Constellation** | GPS L1CA | Primary test signal |
| **PRN** | 1 | Single-satellite focus for initial bring-up |
| **Sample Rate** | 4 MHz | Matches ZedBoard/ADRV9361 typical decimation |
| **True Doppler** | 1250 Hz | Simulated satellite motion |
| **Local Doppler** | 1255 Hz | 5 Hz offset to induce carrier phase rotation |
| **Code Phase** | 347.0 chips | Known initial alignment |
| **Duration** | 10 seconds | Provides 10,000 potential epochs (processed 100 for ref) |

### Golden Reference Model Verification
The Python model (`golden_reference_model.py`) computes the expected I&D values by performing:
1.  **Carrier Wipe-off:** Complex mixing with local NCO sine/cosine waves.
2.  **Code Correlation:** Multiplying wiped samples by Early/Prompt/Late C/A code chips.
3.  **Accumulation:** Summing products over 4000 samples (1 ms epoch).

**Verification Results:**
-   **I_P/Q_P Pattern:** Sinusoidal variation confirming correct carrier phase rotation (5 Hz beat frequency).
-   **Code Advancement:** Exact 1023.000 chips per epoch, matching GPS specification.
-   **Data Format:** Binary output (`golden_ref_data.bin`) prepared for direct ingestion by Verilog testbenches.

## Phase 1: FPGA RTL Implementation & Verification

### Core DSP Modules Implemented
| Module | Function | Hardware Mapping |
|--------|----------|------------------|
| `carrier_nco.v` | 48-bit phase accumulator + Sincos ROM | Block RAM (4096 entries, 18-bit signed) |
| `carrier_mixer.v` | Complex wipe-off (I/Q mixing) | 4x DSP48 Multipliers + Adders |
| `code_nco.v` | 32-bit fractional code phase tracker | 32-bit Accumulator with wrap logic |
| `ca_code_gen.v` | C/A Code lookup (All 32 PRNs) | Shared Block RAM (15-bit address: {PRN, Chip}) |
| `correlator.v` | Early/Prompt/Late Integrate-and-Dump | 6x DSP48 MAC units, 32-bit accumulators |
| `tracking_channel.v` | Top-level per-channel wrapper | Wires NCOs, Mixer, and Correlator |
| `axi_scalar_tracker.v` | Multi-channel AXI-Lite wrapper | Register file for NCO config and I&D readout |

### Testbench & Simulation Results
-   **Testbench:** `tb_tracking_channel.v` reads `synthetic_gps_l1ca.bin` and `golden_ref_data.bin`.
-   **Verification:** Compared Verilog I&D outputs against Python truth for 100 consecutive epochs.
-   **Result:** **PASS**. Maximum absolute error across all I/Q channels was **2 LSB**, attributed to fixed-point rounding differences between Python `float` and Verilog `signed [17:0]`.

### ROM Initialization Automation
-   **Sine/Cosine:** Generated `sincos_table.coe` (4096 entries) for the Carrier NCO.
-   **C/A Codes:** Generated `ca_code_all_prns.hex` (32,736 bits) for a single shared BRAM architecture, optimizing resource usage compared to 32 individual ROMs.

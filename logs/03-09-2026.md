               ↓
┌─────────────────────────────────────────┐

│   - Moves to next bin                   │

#### Implementation Details:

**New Module: `doppler_search_controller.v`**
- **State Machine:** 7 states (IDLE → CALC_DOPPLER → START_ACQ → WAIT_ACQ → COMPARE → NEXT_BIN → DONE)
- **Doppler Grid:** 11 bins from -5000 Hz to +5000 Hz in 1000 Hz steps
- **NCO Calculation:** Pre-computed step constant `48'h00000053E2D623` for 1000 Hz @ 200 MHz
- **Signed Arithmetic:** Proper 2's complement handling for negative frequencies
- **Resource Cost:** ~0 BRAM, ~0 DSP, ~200 LUTs (pure FSM logic)

**Testbench Integration:**
- Removed manual `for` loop from testbench
- Testbench now acts as "RF front-end" (streams data on demand)
- Controller autonomously orchestrates entire 2D search
- Added comprehensive state monitoring for both controller and DUT

#### Parallelism Strategies Evaluated:

| Strategy | Speedup | BRAM Cost | Feasibility |
|----------|---------|-----------|-------------|
| Fully Parallel (11 FFTs) | 11× | 176 BRAM | ❌ Doesn't fit |
| 4-Parallel FFTs | 3.7× | 85 BRAM | ✅ Fits |
| Pipelined + Parallel Peak Det | 1.9× | 66 BRAM | ✅ **Best choice** |
| Serial (current) | 1× | 61 BRAM | ✅ Baseline |

**Decision:** Start with serial approach, add pipelining later if needed.

#### Doppler Search Strategy:
**Evaluated three approaches:**

1. **Uniform Fine Step (250 Hz):** 41 bins, 6.2 ms/PRN - Oversampled
2. **Two-Stage Coarse+Fine:** 32 bins total, 4.8 ms/PRN - **Recommended**
3. **Current (1000 Hz):** 11 bins, 1.65 ms/PRN - Baseline

**Decision:** Implement two-stage search in future (coarse 1000 Hz → fine 50 Hz).

## 🔄 In Progress

### NCI Accumulator Design
**Started implementation of `nci_accumulator.v` module:**

**Design Goals:**
- Accumulate I² + Q² over 20 consecutive 1ms frames
- Immune to navigation bit transitions (50 bps, 20ms period)
- Expected sensitivity gain: ~13 dB (10× weaker signal detection)

**Module Skeleton Created:**
```verilog
module nci_accumulator #(
    parameter FFT_SIZE   = 4096,
    parameter DATA_WIDTH = 18,
    parameter MAG_WIDTH  = 32,
    parameter NCI_FRAMES = 20
)(
    input  wire clk, rst_n,
    input  wire start,
    output reg  nci_done,
    input  wire fft_out_valid,
    input  wire signed [DATA_WIDTH-1:0] i_in, q_in,
    input  wire fft_tlast,
    output wire [MAG_WIDTH-1:0] mag_out,
    input  wire [11:0] read_addr,
    output reg  mag_valid
);
```

**Key Design Decisions:**
- **Memory Reset:** Sequential clear over 4096 cycles (20.48 µs)
- **Overflow Protection:** Shift right by 8 bits (not 4) to prevent overflow over 20 frames
- **Frame Boundary Detection:** Use `fft_tlast` signal from Xilinx FFT IP
- **Resource Cost:** ~5 BRAM36, ~2 DSP48, ~300 LUTs

**Status:** Skeleton created, logic implementation pending

## 🐛 Bugs Encountered & Solutions

### Bug #1: Verilog-2001 Compilation Errors
**Error:** `VRFC 10-8885: declarations are not allowed in an unnamed block`

**Cause:** Declared variables inside `for` loop in testbench

**Fix:** Moved all variable declarations to module level:
```verilog
// ❌ WRONG (inside for loop)
for (i = 0; i < NUM_BINS; i = i + 1) begin
    integer doppler_hz;  // Error!
    ...
end

// ✅ CORRECT (module level)
integer doppler_hz;
...
for (i = 0; i < NUM_BINS; i = i + 1) begin
    doppler_hz = ...;  // OK
end
```

### Bug #2: Controller Not Triggering Acquisition
**Symptom:** Testbench hung waiting for `done` signal

**Root Cause:** Controller checked `if (acq_start == 1)` instead of `if (start == 1)`

**Fix:** Corrected the condition to check the input `start` signal, not the output `acq_start`

### Bug #3: Start Pulse Not Cleared
**Symptom:** `acq_start` stayed high forever after first assertion

**Fix:** Explicitly deassert in `ST_WAIT_ACQ` state:
```verilog
ST_WAIT_ACQ: begin
    acq_start <= 1'b0;  // Clear the pulse
    if (acq_done) state <= ST_COMPARE;
end
```

## 📚 Technical Notes

### GNSS Acquisition Theory
- **FFT-based correlation:** O(N log N) vs O(N²) time-domain
- **Doppler resolution:** Δf = 1/T (1ms → 1000 Hz, 20ms → 50 Hz)
- **NCI benefit:** 10× integration time → 10 dB sensitivity improvement
- **Bit transition issue:** 50 bps nav bits flip every 20ms, coherent integration must stay within one bit

### Xilinx FFT IP Configuration
- **Mode:** Radix-4 Burst I/O
- **Scaling:** Block Floating Point (BFP)
- **Data Width:** 18-bit input, 48-bit internal
- **Latency:** ~15 µs for 4096-point FFT @ 200 MHz

### AXI4-Stream Handshake
- **Critical:** `tvalid` must stay high until `tready` is asserted
- **Common pitfall:** Dropping `tvalid` too early causes data loss
- **Solution:** Hold `tvalid` until handshake completes

### DC Bias Removal (Testbench)
```verilog
// Calculate mean
for (i = 0; i < FFT_SIZE; i = i + 1) begin
    sum_i = sum_i + $signed(stim_i_mem[i]);
    sum_q = sum_q + $signed(stim_q_mem[i]);
end
mean_i = sum_i / FFT_SIZE;
mean_q = sum_q / FFT_SIZE;

// Subtract mean
for (i = 0; i < FFT_SIZE; i = i + 1) begin
    stim_i_mem[i] = stim_i_mem[i] - mean_i;
    stim_q_mem[i] = stim_q_mem[i] - mean_q;
end
```
